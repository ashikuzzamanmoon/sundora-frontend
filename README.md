# Sundora Frontend

This is the frontend for Sundora, a modern and elegant e-commerce platform for beauty products. It's built with [Next.js](https://nextjs.org) and [TypeScript](https://www.typescriptlang.org/), offering a fast, responsive, and user-friendly shopping experience.

#### Live link: [https://sundora.vercel.app](https://sundora.vercel.app/)

## Features

- Product Catalog: Browse products by category, brand, or special collections like "New Arrivals" and "Sale".

- Advanced Filtering: Filter products by price, brand, gender, category, sub-category, and size.

- Product Details: View detailed product information, including image galleries, descriptions, and pricing for different variants (size or color).

- Shopping Cart: Add products to a cart, update quantities, and view a summary of the order.

- Checkout Process: A multi-step checkout process for shipping and payment information.

- Search: Search for products with a real-time search bar and a dropdown of results.

- Responsive Design: Fully responsive layout for a seamless experience on desktop, tablet, and mobile devices.

- Stories/Blog: A section for articles and featured content.

## Getting Started

To run this project on your local machine, follow these steps:

### Prerequisites:

- [Node.js](https://nodejs.org/en) (v18.18.0 or newer)
- [npm](https://www.npmjs.com/)/[yarn](https://yarnpkg.com/)/[pnpm](https://pnpm.io/)/[bun](https://bun.sh/)

### Installation:

1. Clone this repository:

```bash
git clone https://github.com/ashikuzzamanmoon/sundora-frontend.git
```

2. Navigate to the project directory:

```bash
cd sundora-frontend
```

3. Install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

4. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Now, you can view the project by visiting [http://localhost:3000](http://localhost:3000) in your browser.
